# New Horizons Hub v0.1.0

## Changes

### First release

This is the first release of the New Horizons Hub firmware as its own
repo, split out of `NewHorizonsOS-OTA/firmware/newhorizons_hub/` now that
its feature set has diverged into a genuinely separate product:

- ESP-NOW event-driven polling (HELLO/PAIRED/POLL) to pair with wearable
  devices directly, no LAN Gateway software required.
- WebSocket uplink to a New Horizons Desktop Backend, with the same
  hello/gateway_status heartbeat protocol a software Gateway uses.
- Reverse command channel: Backend-issued device commands relayed to a
  paired device over ESP-NOW, with retry/pacing.
- SoftAP setup portal (WiFi + which Backend to reach) — the *only* web
  server this firmware ever runs; it does not persist into normal
  operation.
- Remote management from the Desktop app's Relays page ("Manage" on the
  Hub's card): live status, settings changes (`set_config`), paired-device
  list, LAN device scan/migrate, and factory reset — all over a
  `gateway_command`/`gateway_command_result` message pair on the same WS
  connection, since the Hub has no `device_uid` for the existing
  device-command routing to key off of.
- Boot-time OTA auto-update, verified via SHA256, pointed at this repo's
  own `releases/hub-gcu-v23d-lts-latest.json`.

Every module has been validated end to end on real hardware (GCU V2.3.D
Hub + a real wearable device board) prior to this first release.
