# v0.9.0

## 更新通道（正式版／測試版）

- Hub 可以選 `stable`（正式版，預設）或 `beta`（測試版），從 Desktop 的 Hub 管理視窗切換（新的 `set_update_channel` 指令），不需重開機。
- stable 讀 `hub-gcu-v23d-lts-latest.json`，beta 讀 `hub-gcu-v23d-lts-beta.json`；beta 也會收到每個正式版。
- 測試版版號 `vX.Y.Z-beta.N` 排在對應正式版之前；從 beta 切回 stable 不會降級，會等正式版追上。
- 出廠重置會回到 stable。
- `gateway_status` 的 `update` 區塊新增 `channel`、`resolved_manifest_url`。

## OTA 安全性

- Hub 自己的更新，以及代替 ESP-NOW 裝置抓 manifest／韌體時，都改為驗證 HTTPS 憑證（內建 Mozilla 根憑證），不再接受任何人。不檢查到期日。

## 修正

- 「只有第一次開機才格式化 SPIFFS」的保護從沒生效：NVS 鍵名 `spiffs_initialized` 超過 15 字元，一直寫入失敗。改為 `spiffs_init`。

## 建置

- board define 改走 `compiler.cpp.extra_flags`，不再覆寫 core 的 `build.extra_flags`（以前要手動補 `-DESP32=ESP32`）。序列埠不再出現 core 自己的 `[E]` 訊息，韌體約小 48 KB。
- 發布腳本支援 `CHANNEL=beta`，並拒絕把測試版寫進 `-latest.json`。

## 相容性

- 搭配 Desktop v0.22.0 才有 Hub 通道切換的 UI。
- 搭配裝置韌體 v1.14.0：經 Hub 的裝置 OTA 一樣走憑證驗證。
