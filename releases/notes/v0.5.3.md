# v0.5.3

## 板子型號再改名:TIA-CTL/R → TIA-CTL

名稱裡的「/R」原本指跨阻級的回授電阻 Rfb。電路上 Rfb 仍然存在,但名稱不再標示它。
與裝置韌體 New Horizons OS v1.8.1 同步。

- Hub 的型號(`kHardwareModel`)改成 `TIA-CTL v2.3.D GCU LTS (Hub)`。
- **OTA 不受影響**:manifest 的 `model` 仍是 `VD-CTL/R v2.3.D GCU LTS (Hub)`(`kOtaManifestModel`),
  v0.5.1 以前的 Hub 和 v0.5.2 都接受,可以直接 OTA 到這版。

## 驗證

- `arduino-cli` release build 通過;binary 同時帶有 TIA-CTL 與 VD-CTL/R 兩個名稱。
- **尚未實機驗證**:v0.5.1 或 v0.5.2 的 Hub 應能 OTA 到 v0.5.3。

## 相容性

- 不改變 ESP-NOW 或 uplink 的線路格式。
