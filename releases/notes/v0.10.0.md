# v0.10.0

**和裝置韌體共用同一份程式碼（`nhos_core`），並修正經 Hub 更新裝置時偶爾出現 `relay_already_active`。**

這是 v0.10.0-beta.1～beta.2 的正式版。

## 共用程式碼

- 板子定義、封包常數、ESP-NOW 封包切分、對時封包、時鐘核心、版本排序、更新通道、OTA 憑證、JSON 工具，改用韌體 repo 的 `firmware/libraries/nhos_core`，和裝置韌體是同一份。以前的副本已刪除，副本裡過時的板子定義（沒指定板子會靜默退回 v1.0.F、v2.1 矩陣大小錯誤、缺 v1.5.F）也一起消失。
- 編譯需要把 NewHorizonsOS-OTA 放在本 repo 旁邊（腳本與 CI 會處理）。發布時會拒絕使用有未 commit 修改的函式庫，並在說明末尾記錄所用的韌體 commit。

## 修正

- 同一台裝置再次要求轉送韌體時不再被拒絕：
  - 同一個檔案、還沒開始送：Hub 再回一次「開始」。這是 Hub 連 GitHub 那幾秒內，裝置重送請求的情況。
  - 已經送過或換了檔案：表示裝置在轉送途中重開了，Hub 結束舊的轉送、重新開始。
  - 其他裝置的請求仍會被拒絕，直到目前的轉送結束。

## 相容性

- 與裝置、與 Desktop 之間的協定都沒變。
- 建議搭配裝置韌體 v1.15.0、Desktop v0.24.4。

Built with nhos_core from NewHorizonsOS-OTA 7a64ff7.
