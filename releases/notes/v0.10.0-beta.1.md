# v0.10.0-beta.1（測試版）

**建置結構調整：和裝置韌體共用的程式碼，改成直接使用韌體 repo 的 `nhos_core` 函式庫，不再自己保留一份副本。功能不變。**

這是測試版，只發布在 beta 通道（`hub-gcu-v23d-lts-beta.json`）。在 Desktop 的 Hub 管理視窗把通道切到 beta 才會收到。

## 共用程式碼

- 板子定義、封包常數、ESP-NOW 封包切分、對時封包、時鐘核心、版本排序、更新通道、OTA 憑證、JSON 工具，改用 `NewHorizonsOS-OTA/firmware/libraries/nhos_core`，和裝置韌體是同一份。以前的副本已刪除。
- 以前 Hub 的 `BoardConfig.h` 副本已經過時（沒指定板子時會靜默退回 v1.0.F、v2.1 的矩陣大小寫錯、缺 v1.5.F），現在改用韌體的版本，這些問題一起消失。
- 編譯需要把 NewHorizonsOS-OTA 放在本 repo 旁邊（腳本與 CI 會自動處理）。發布時會拒絕使用有未 commit 修改的函式庫，並在這份說明末尾記錄所用的韌體 commit。
- 韌體大小與 v0.9.0 相同。

## 相容性

- 與裝置之間的 ESP-NOW 協定、與 Desktop 之間的 WebSocket 協定都沒變。
- 建議搭配裝置韌體 v1.15.0-beta.3。

Built with nhos_core from NewHorizonsOS-OTA fc83113.
