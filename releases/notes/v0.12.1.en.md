# v0.12.1

**The Hub now joins Wi-Fi at a fixed 20 MHz bandwidth, for wider compatibility with access points.**

## Changes

- **Wi-Fi is fixed to HT20.** The Hub's one radio both joins the AP (its uplink) and receives devices' ESP-NOW. The bandwidth used to be left unset, so behind an AP set to 40 MHz (or 20/40 auto) the Hub went to HT40 as well, while devices always send ESP-NOW at 20 MHz on a single channel. The station is now fixed to 20 MHz before it connects, so ESP-NOW reception no longer depends on the AP's bandwidth setting. The uplink only relays sensor data and has no use for 40 MHz.
- This is a precaution. In the lab, the previous version paired fine behind a 40 MHz AP, so it is not the fix for any known pairing failure.
- Once connected, serial shows `wifi_sta_channel primary=N second=M` (`second` 0 means 20 MHz), so the channel the Hub actually uses can be checked on site.

## Compatibility

- Hub only. No device, Gateway or Desktop update needed; device firmware v1.19.1, released alongside, is a separate change.
- Paired devices, settings and the pairing flow are unchanged.
- Once this is out, older Hubs enter "update required": paired devices keep relaying, but new pairings and settings changes are paused until no device has been online for a full minute, then the Hub updates itself.
