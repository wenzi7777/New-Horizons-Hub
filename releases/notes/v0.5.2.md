# v0.5.2

## 板子型號改名:VD-CTL/R → TIA-CTL/R

壓力矩陣的讀出電路是跨阻放大(TIA),不是分壓,所以產品名改成 TIA-CTL/R。
與裝置韌體 New Horizons OS v1.8.0 同步。

- Hub 的型號(`kHardwareModel`)改成 `TIA-CTL/R v2.3.D GCU LTS (Hub)`。
- `BoardConfig.h` 新增 `NHOS_BOARD_OTA_MODEL`(改名前的 `VD-CTL/R …`),`Config.h` 新增
  `kOtaManifestModel`。`OtaManager::parseManifest()` 兩個名稱都接受。
- **manifest 的 `model` 繼續寫 `VD-CTL/R v2.3.D GCU LTS (Hub)`**:v0.5.1 以前的 Hub 只接受
  完全相同的名稱,維持舊名它們才能直接 OTA 到這版。`build_release.sh` 的 `MODEL` 因此不變。

## 驗證

- `arduino-cli` release build 通過;binary 同時帶有 TIA 與 VD 兩個名稱。
- **尚未實機驗證**:v0.5.1 的 Hub 應能 OTA 到 v0.5.2,之後再 OTA 也不應出現 `model_mismatch`。

## 相容性

- 不改變 ESP-NOW 或 uplink 的線路格式。
- 經 Hub 轉送的裝置 ESP-NOW OTA 由裝置韌體自己比對 `model`,v1.8.0 同樣接受兩個名稱。
