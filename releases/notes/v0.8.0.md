# v0.8.0

## 從 Desktop 更新 Hub

搭配 Desktop v0.20.0 的 Hub 管理頁。

- **新的 Hub 指令**：
  - `check_update`：讀取 GitHub 上的 manifest，回覆目前版本、最新版本、是否有更新與發布說明連結。
  - `apply_update`：先回覆 `update_started`，接著下載新韌體並重開。下載期間 Hub 不轉發資料，約 1–2 分鐘。
- **`gateway_status` 新增 `update` 區塊**：最近一次檢查或更新的狀態（階段、版本、錯誤），Desktop 用它判斷更新是否成功。
- 開機時的自動更新照舊。

## 裝置斷線的判斷

- 每台配對裝置的 `connected` 改看「最近 15 秒內是否收到它的封包」。配對中的裝置每 6 秒會送一次 HELLO。
  - 以前一律回報在線，直到 30 秒沒消息才直接從清單消失，Backend 看不到明確的斷線。
  - 現在安靜下來的裝置會明確回報斷線，和 Gateway 一致。
- Hub 代裝置回報的失敗（`command_delivery_timeout` 等）加上 `"live_seen": false`，Backend 不會因此把已斷線的裝置當成在線。

## 相容性

- 舊版 Backend 會忽略 `update` 區塊與 `live_seen`。
- 斷線判斷的主要修正在 Backend（Desktop v0.20.0），舊版 Hub 也適用。
