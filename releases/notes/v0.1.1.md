# New Horizons Hub v0.1.1

## Changes

### Improved: ESP-NOW link now runs at a much faster PHY rate

- Each paired device's ESP-NOW link now runs at `WIFI_PHY_RATE_MCS3_LGI`
  (~26Mbps) instead of ESP-NOW's default `WIFI_PHY_RATE_1M_L` (1Mbps),
  configured via `esp_now_set_peer_rate_config()` right after
  `esp_now_add_peer()` in `EspNowHubManager::registerPeerIfNeeded()`.
  Matches the same change shipped in `NewHorizonsOS-OTA` v0.12.1 for the
  device side of the link — see that repo's
  `firmware/spikes/README.md` ("PHY rate config" section) for the full
  real-hardware measurement table this value was chosen from.
- Non-fatal if the rate-config call fails on a given board/core — falls
  back to the default rate rather than blocking that device's pairing.
- No protocol or frame-format changes; existing paired devices keep
  working. Real-hardware end-to-end validated: a device running
  `NewHorizonsOS-OTA` v0.12.1 paired cleanly and forwarded frames to a
  local Desktop Backend through this Hub without incident.
