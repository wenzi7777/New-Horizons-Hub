# v0.11.0

**新的 Hub 設定頁：支援日文、英文、繁中，存檔前會先試連 Wi-Fi 和伺服器；備援設定用網路改名為 `NHHub-…`，不再和裝置撞名。**

## 設定頁

- 改版成新的設定頁，和裝置韌體（v1.17.0）共用同一份。主色是紫色，標題旁有「Hub」標籤，跟裝置的設定頁一眼就能分出來。
- **三種語言**：日本語、English、繁體中文。預設依手機語言自動選擇，右上角可以切換。
- **頁面分成「Wi-Fi」和「伺服器」兩區**：
  - 伺服器用分段按鈕選擇「正式 / 本機 / 自訂」，只有選「自訂」時才會出現網址欄。
  - 網址必須以 `ws://` 或 `wss://` 開頭。
- **Auth Token**：
  - 收在「進階」裡。
  - 頁面不會再顯示已存的 Token。設定用網路是開放的，任何人連上都看得到，所以只顯示「已儲存」；留空就沿用原本的 Token。
- **重設**：「清除設定」移到頁面最底下的「重設」區。清除時會一併把更新通道設回 stable，跟快速斷電重設的結果一致。
- **網路清單**：
  - 同名網路只列一次，依訊號強弱排序。
  - 有「其他網路…」可以手動輸入。
  - 可以切換顯示密碼。
  - 密碼留空會沿用已存的密碼。
- **輸入與送出**：錯誤訊息顯示在出錯的欄位旁，已經輸入的內容不會清掉；送出後按鈕會停用，避免重複送出。

## 先試連再儲存

- 設定用網路會保持開著，在背景試連 Wi-Fi，最多 15 秒。
- Wi-Fi 連上後，再用 TCP 連一次伺服器：
  - 連得到才算正常。
  - 連不到只會顯示警告，設定照樣儲存。
  - 選「本機」時不檢查。
- 只有 Wi-Fi 試連成功才會儲存並重新啟動。失敗時會顯示原因（密碼錯誤、找不到網路、逾時）。
- 已有的 Gateway ID 會沿用，不會每次儲存都產生新的。

## 備援設定頁

- 已存的 Wi-Fi 在開機時連不上時，Hub 會開一個只有 Wi-Fi 設定的頁面。
- 這個頁面的設定用網路以前叫 `NHOS-<MAC>`、網址是 `nhos.os`，跟裝置的完全一樣。現在改為 `NHHub-<MAC>` / `http://nhos.hub`，跟首次設定頁一致。
- 在備援頁儲存後，Hub 會重新啟動。以前是直接連線、不重開。

## 效能

- 掃描改在背景進行，開頁面時不再卡住 loop。在備援模式下，ESP-NOW 轉送也不再被打斷。
- 頁面以 gzip 壓縮放在 flash 裡直接送出，不占用 heap。
